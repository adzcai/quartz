Kullback-Leibler divergence

2 min read

the average surprise of a distribution is the entropy

\begin{align*}
\mathcal{H}(p) &:= \mathop{\mathbb{E}}_{x \sim p}\left[  \log p(x)^{-1} \right]\\
&=  \sum_{x \in \mathcal{X}} p(x) \log p(x)^{-1} \\
\end{align*}
Link to original

but my average surprise if I think is the cross entropy

\mathcal{H}(p \parallel q) = \mathop{\mathbb{E}}_{x \sim p}[ \log q(x)^{-1}]
Link to original

the difference is the Kullback-Leibler divergence

\begin{aligned}
f(\lambda) &= \lambda \log \lambda \
\nabla f(\lambda) &= 1 + \log \lambda
\end{aligned}

\begin{aligned}
f(\lambda) &= - \log \lambda \
\nabla f(\lambda) &= - \frac{1}{\lambda}
\end{aligned}

\text{KL}(p \xleftrightarrow{ \alpha } p’ \parallel q \xleftrightarrow{ \alpha } q’) \le \text{KL}(p \parallel q) \xleftrightarrow{ \alpha } \text{KL}(p’ \parallel q’)

\begin{aligned}
f(q) &= \text{KL}(q \parallel p) \
f^{*}(m) &= \mathop{\text{lse}}_{z \sim p} m(z)
\end{aligned}

\text{KL}(p \parallel q) = - \mathop{\mathbb{E}}{ y \sim p }[\log y] \geq -\log \mathop{\mathbb{E}}{ y \sim p } y = - \log_2 1 = 0
