maximum entropy

The maximum entropy principle / entropy prior:
The distribution that most accurately reflects the current state is the one with the greatest entropy.
A formalization of Occams razor.

most named distributions maximize entropy under some constraints:

  • discrete Uniform maximizes entropy given support over a finite set
  • Uniform distribution maximizes entropy given support over an interval
  • Normal maximizes entropy given mean and variance
  • Gibbs distribution maximizes entropy given energy function

See also Occams razor and max ent rl

temporal difference learning

a temporal difference learning algorithm (for the purposes of these notes)
is one that does value approximation via gradient descent on the squared temporal difference error.
this gives the update rule

where is some learning rate and is the value target computed from the trajectory.
different value targets give different algorithms.
the scalar coefficient is the temporal difference error.

this update rule could be considered the “fundamental theorem of rl”;
aka “approximate dynamic programming” (compare with dynamic programming)
or “semi gradient” (eg Sutton and Barto)
since we stop gradient on the value targets even when they “bootstrap” using the current parameters.
(in practice people use target networks to stabilize training.)

we can turn these into control algorithms
by acting according to an epsilon greedy policy
and updating via the above rule.
this is an actor critic algorithm where we can compute the greedy policy
(e.g. discrete action space).
the algorithms that do this using are called sarsa(λ), expected sarsa, Q learning respectively.
