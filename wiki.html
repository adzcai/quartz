Hopfield networks

tutorial on Hopfield networks

introduction

  1. How do we remember things?
  2. Hopfield networks solve the associative memory task in a biologically plausible way
  3. autapses harm the stability of Hopfield networks
  4. Hebbian learning on a single pattern memorizes the pattern up to sign

capacity

  1. the crosstalk between patterns is responsible for incorrect memorization
  2. the error probability scales proportionally to the number of patterns and inversely proportionally to the size of the network
  3. the maximum capacity of a Hopfield network is linear in the network size if some errors are allowed but sublinear when most patterns need to be perfect

energy

  1. one can construct an energy function for undirected Hopfield networks that aids in analysis at the cost of sacrificing biological plausibility
  2. memorized patterns are not the only energy minima
  3. higher temperature results in a stochastic update rule
  4. ferromagnets are uniformly connected Hopfield networks and undergo a phase transition at their critical temperature
  5. the system dynamics can be derived from the energy function

continuous

  1. rate model for continuous time recurrent networks
  2. energy function for continuous Hopfield networks
