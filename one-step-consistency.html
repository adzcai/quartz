taking the expectation of both sides over a policy’s trajectory distribution
and conditioning on an initial state or state-action pair
gives nice identities for the value:

i.e. a policy’s “Bellman operator” updates the value function
by taking one step, observing the reward,
and then evaluating the next state using the given value function.

it’s a contracting map in the supremum norm and the actual value function / Q function is its unique fixed point:
