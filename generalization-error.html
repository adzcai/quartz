generalization error

1 min read

suppose we’ve obtained a prediction rule .
how well does it do on unseen inputs?
ie what’s the expected value when we evaluate the loss function over the true data generating process:

  • eg the test error using the zero-one loss is the misclassification probability.

many ways to estimate this quantity. see model assessment

suppose is learned from some training dataset (eg by erm).
we say it generalizes if it performs well on unseen data (low test error). generalization is thought to be a core component of intelligence. compare with overfitting / memorization

Not to be confused with risk
which evaluates the optimization algorithm (not the specific prediction rule)
