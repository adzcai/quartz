associative memory

1 min read

The associative memory task is basically to do “fuzzy” content retrieval
(aka content-addressable memory):

  1. At initialization, I’ll “store” bit-vectors of length (called patterns).
  2. Then, given a new pattern,
    you output the stored pattern that’s “closest”, ie has the most matching bits.

One naive way to do this is to iterate through all the stored vectors, compute the number of bits that match the input vector, and return the closest one. This takes time where is the number of patterns and is the length of each pattern.

Generalizing beyond bit-vectors, you could think of this as a sort of search engine or generative model;
eg “What’s the name of that movie again?”
You could just type in a few keywords and the content-addressable memory would return the closest match.
