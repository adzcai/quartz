interpolate

1 min read

Consider some labelled dataset .
We say a prediction rule interpolates the dataset if for all
(ie zero train loss for L2 loss or zero-one loss)

note for a linear prediction rule (possibly with basis expansion)
this is equivalent to solving a system of linear equations.
See polynomial interpolator for an important case.

In general:
When will a machine learning method find an interpolator?
Depends on machine inductive bias:

  1. prediction rule class must be expressive enough to contain the data generating process / ground truth (i.e. model complexity must pass the interpolation threshold)
  2. the fitting method must actually find it
  3. the regularization term must not be too large (otherwise we’re minimizing a different loss function)

linear mode connectivity suggests that all interpolators lie on some connected manifold

overfit

We say an (approximate) interpolater overfits
if it achieves high generalization error / doesn’t generalize.
(Used pretty heuristically, not a rigorous definition.)

We’d typically expect an overparameterized model class to overfit often since it might capture spurious noise in the training data and not the actual desired signal.

But instead, in many cases, we observe double descent
in which even more complex architectures actually generalize well (achieve low test error).
Why? See there.
